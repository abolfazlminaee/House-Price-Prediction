# House-Price-Prediction
▎Overview
این پروژه به منظور پیش‌بینی قیمت آپارتمان‌ها در تهران با استفاده از داده‌های واقعی طراحی شده است. هدف اصلی این است که با تحلیل ویژگی‌های مختلف آپارتمان‌ها، قیمت آن‌ها را به تومان یا دلار تخمین بزنیم.
▎توضیحات مجموعه داده
ما اطلاعات تقریبا ۴۰۰۰ آپارتمان در تهران را جمع‌آوری کرده‌ایم. داده‌ها در فایل housePrice.csv ذخیره شده‌اند و شامل ویژگی‌های زیر هستند:

• Area: متراژ خانه به متر.

• Room: تعداد اتاق خواب.

• Parking: آیا پارکینگ دارد یا خیر (0 = خیر، 1 = بله).

• Warehouse: آیا انباری دارد یا خیر (0 = خیر، 1 = بله).

• Elevator: آیا آسانسور دارد یا خیر (0 = خیر، 1 = بله).

• Address: آدرس حدودی در تهران (ممکن است برخی از خانه‌ها آدرس نداشته باشند).

• Price: قیمت به تومان.

• Price(USD): قیمت به دلار.
